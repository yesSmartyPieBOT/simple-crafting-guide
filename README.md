# Simple Crafting Guide

A lightweight client-side Fabric mod for Minecraft 1.21.11 that lets players browse crafting recipes in-game.

## Planned first version
- Search recipes by item name
- Browse available crafting recipes
- Show ingredients, crafting pattern, and output
- Lightweight GUI with a configurable keybind
- Works with recipes registered by the current game and installed mods

## Build
Requires JDK 21.

```bash
./gradlew build
```

The mod JAR will be created in `build/libs/`.

Project scaffold being initialized. Gameplay features and compatibility will be added and tested incrementally.

# Simple Crafting Guide

A client-side Fabric mod for Minecraft 1.21.11 that opens a cyberpunk-style recipe browser with the configured keybind.

## Build
Requires Java 21. GitHub Actions builds the mod on every push to `main` and uploads the compiled JARs as the `simple-crafting-guide-jars` artifact.

The built mod JAR is produced in `build/libs/`.
